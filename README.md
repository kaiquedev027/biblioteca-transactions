# Biblioteca MongoDB Transactions

Projeto desenvolvido para demonstrar o uso de Transactions ACID no MongoDB.

## Tecnologias

- Node.js
- MongoDB
- Mongoose

## Funcionalidades

- Registrar empréstimo de livros
- Devolver livros
- Controle transacional com rollback

## Requisitos

MongoDB executando como Replica Set.

## Instalação

npm install

## Execução

node src/app.js
